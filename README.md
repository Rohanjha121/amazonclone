# 🛒 Amazon Clone

A full-stack **Amazon Clone E-commerce Web Application** built to replicate the basic shopping experience of Amazon.
This project demonstrates modern **full-stack development** using **React, Node.js, Express, and PostgreSQL**.

The application allows users to browse products, view product details, explore promotional offers, and manage a shopping cart through a responsive interface.

---

# 🚀 Features

* **Product Browsing** – View products in an Amazon-style layout
* **Product Details Page** – Detailed view of selected products
* **Add to Cart** – Manage items in the shopping cart
* **Search Functionality** – Quickly find products
* **Image Carousel** – Promotional product banners
* **Bank Offers Section** – Display special offers
* **Responsive UI** – Works across multiple screen sizes
* **Modern UI Components** – Built using React components

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/AmazonClone.git
cd AmazonClone
```

---

## 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

Run backend server:

```bash
npm run dev
```

or

```bash
npm start
```

---

## 3️⃣ Install Frontend Dependencies

Open another terminal and run:

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```
